# RideWithUBT

An offline-first virtual world for indoor cycling training.

Ride a real place on a home trainer, follow a structured workout, and keep the
recording. Everything runs on your own machine: there is no account to create
and no server that has to be up for you to ride. Uploads go straight from the
app to Garmin Connect or Strava, never through a RideWithUBT server.

**Status: early. Nothing is released yet** - the roadmap is in
[docs/architecture.md](docs/architecture.md).

## What it is meant to do

- **Ride a real place.** Worlds are generated by code from data tracked in this
  repository - OpenStreetMap geometry, open elevation data and textures authored
  here. The first one is the Sokol International Racetrack near Almaty.
- **Read your sensors** over Bluetooth Low Energy or ANT+ (with a USB stick):
  power, speed, cadence, heart rate.
- **Drive a smart trainer** over FTMS or Tacx FE-C, so intervals hold their
  target and gradients are felt rather than displayed.
- **Work without a smart trainer too.** With a plain trainer, a speed sensor and
  your wheel and tyre size, the app computes power from a trainer curve. If you
  own a power meter, you can measure your own trainer's curve and contribute the
  profile back as a pull request.
- **Run structured workouts** imported from Garmin Connect or from
  `training_plan_generator` JSON.
- **Keep everything in one place** - one static data directory holds the
  settings, the generated worlds and every recorded ride as a FIT file.
- **Speak three languages**: Russian, English and Kazakh.

Riding with other people is a later, opt-in feature. The app is built to stay
fully usable with it switched off.

## Running from source

Requires [uv](https://docs.astral.sh/uv/).

```bash
uv sync
uv run ridewithubt                # open the window
uv run ridewithubt --languages    # list the available languages
uv run ridewithubt --lang kk      # override the saved language for one run
uv run ridewithubt --selftest     # boot the engine with no window and exit
```

## Development

```bash
uv run pytest                     # tests, coverage gate 90%
uv run ruff check .
uv run ruff format --check .
uv run mypy app tests
uv run pre-commit install         # once, to run the same gate on commit
```
