# RideWithUBT

An offline-first virtual world for indoor cycling training.

Ride a real place on a home trainer, follow a structured workout, and keep the
recording. Everything runs on your own machine: there is no account to create,
no server to depend on, and no ride data leaving the computer unless you ask
for it. Uploads go straight from the app to Garmin Connect or Strava, never
through a RideWithUBT server.

Work in progress. Nothing here is released yet.
